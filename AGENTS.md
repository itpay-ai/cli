# Agent entry points

Before preparing, merging or publishing a CLI release, read [docs/NPM_RELEASE.md](docs/NPM_RELEASE.md) and the current `.github/workflows/cd.yml`. A version bump merged to main can publish automatically. Preserve existing changes and confirm the authorized distribution channel; `latest` is stable and `next` is preview.

Do not put tokens, OTPs or passkey material in chat or repository files.
