# CLI 检查与独立体验

工程检查保护代码、协议、身份、幂等、unknown和资金边界；不代签用户Agent体验。按改动范围用已有定点测试，打包变更 `npm run test:package`，完整发布门禁 `npm run check`。测试使用明确隔离状态/临时前缀，禁改本人现存身份或全局安装。

Services自然旅程：被测Agent只拿Services Skill、其实际包/帮助和运行返回；理解完整地点/条件、必要时定向查证、先给简短路线判断，再Exact/Smart查询、完整结果、按委托选择、仅补必要同意、展示官方入口、沿原任务恢复。不能给源码/正确命令救场。当前V4整体装配缺失，旧环境成功不代表此候选通过。

API自然旅程：另一任务只读API Skill/API帮助，在受限scope/预算中 discover→inspect→绑定publication调用→状态/结果/用量→原任务恢复；不能要求先读铁路或API维护内部材料。购买/充值仍按真实同意和宿主政策，不能用Key权限绕开。

两条旅程分别记实际版本/包hash/材料、耗时、有用结果、人工帮助、约束保持、失败和恢复。完整fakepass仅付款/出票/退款模拟，其余真实链路；当前阶段没有部署/测试环境启用授权。UI核验优先Node+Playwright。未观察宿主、未运行数据库/PSP、工程失败与真实体验结论分别列明。

现有包smoke包含help文档映射、隔离安装及合成OAuth/API跨进程恢复；它不读取新增API Skill/参考页，不能当成入包证据。该缺口见[待办](BACKLOG.md)，不改检查或脚本假装本批已解决。
